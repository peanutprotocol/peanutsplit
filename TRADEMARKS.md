# Trademark and naming draft

This file is a publication draft, not a current software license or a grant of trademark rights.

The intended software license will cover code rights only. It will not grant rights to Peanut,
Peanut Split, Squirrel Labs, their logos, mascots, domain names, or other source-identifying marks
beyond rights that applicable law already permits.

Downstream operators may remove official-host Peanut references. Modified or independently operated
versions must not imply that Squirrel Labs or Peanut sponsors, endorses, operates, or supports them.
Before publication, Squirrel Labs must resolve authority over the “Peanut Split” name and repository
namespace and publish exact, non-discriminatory fork naming guidance.

Trademark rules must not restrict use, modification, or redistribution of the licensed code itself.
They must not become a disguised requirement to preserve promotional links, badges, logos, referral
parameters, or phone-home behavior.
