The generated inventories are publication inputs, not proof of rights, security, or buildability.
An official release's separate public receipt records their distributable hashes and the exact
public tree. Private provenance, reviewer, evidence, source-path, and exclusion records stay in an
external private ledger and are never copied into this distribution.
