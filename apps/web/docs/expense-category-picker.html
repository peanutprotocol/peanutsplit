04 · Proposed behavior

Classification stays helpful, not magical.

What changes

  • The character portrait disappears from expense cards.
  • A category doodle is derived from the description at display time.
  • The original description and “María paid” line remain untouched.
  • Unknown descriptions receive the neutral question doodle.

Guardrails for implementation

  • Specific phrases beat generic words: “gas bill” beats “gas.”
  • Normalize case, accents and punctuation; match on word boundaries.
  • Store no inferred personal data—the category describes the purchase only.
  • Add manual correction only in the expense editor, never on the scan surface.
