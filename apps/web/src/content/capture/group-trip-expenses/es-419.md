# Gastos de viaje en grupo sin hoja de cálculo

Para llevar las cuentas de un viaje necesitas el monto, quién pagó y quiénes compartieron cada gasto. En Peanut Split, todos pueden agregar esos datos desde el mismo enlace. La sala actualiza los saldos y propone quién le paga a quién.

<Steps title="Organiza los gastos del viaje">
<Step title="Crea una sala">Ponle el nombre del viaje y elige la moneda para los saldos.</Step>
<Step title="Comparte el enlace">Cada persona escribe su nombre para entrar. Fija el enlace en el chat para volver a abrir la sala.</Step>
<Step title="Agrega los gastos compartidos">Registra el alojamiento, la comida y el transporte a nombre de quien pagó. Selecciona quiénes participaron en cada gasto. <Cast name="mo" size="sm" /></Step>
</Steps>

## Si prefieres una hoja de cálculo

Usa columnas para la fecha, la descripción, el monto, la moneda, quién pagó y la parte de cada persona. El saldo de cada uno es lo que pagó menos la parte que le corresponde.

Una hoja permite adaptar las fórmulas y agregar columnas. Funciona bien si alguien se encarga de actualizarla. Split sirve cuando varias personas quieren cargar sus gastos desde el teléfono.

## Para tener en cuenta

Split es gratis y no tiene plan de pago.

Split convierte automáticamente 156 monedas al tipo de cambio indicativo del día. Tu banco puede usar otro tipo de cambio.

Puedes agregar gastos sin conexión. Se guardan en tu dispositivo y se envían cuando vuelve la señal. Para editar gastos o registrar pagos necesitas conexión.

Páguense en efectivo, por transferencia o por el medio que acuerden y registren el pago en Split. Split no mueve dinero ni verifica el pago con el banco.
