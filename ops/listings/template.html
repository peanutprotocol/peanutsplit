The Cloudflare blocks are browser-fingerprint blocks, so a human reading a challenge aloud does not help — those need a genuine human browser session. The two highest-intent targets, AlternativeTo and SaaSHub, are both on the wrong side of that line.

Division of labour: roughly four walled targets done by hand, about thirty minutes with every field pre-staged below, while automation takes the open targets and the GitHub list PRs.

The higher-value motion is editorial, not submission

Directory submission is a thin seam: the good ones are walled and several open ones are half-built. The "best Splitwise alternatives" comparison posts that already rank are human-edited lists reached by asking — no bot walls, real referral traffic, and outreach that genuinely automates through the existing mail persona stack.

Mail access

Working, but on a one-day fuse.

The konrad@peanut.me token is gmail.send scope only — deliberate, and not worth widening to read a whole founder inbox for confirmation mail. intern@peanut.me works in a browser but costs a human-read CAPTCHA each sign-in, and IMAP with the account password fails outright because Workspace has disabled password-based IMAP.

Two deadlines

The domain enforces 2SV from 25 August, and the enrolled factor is a passkey — device-bound, so future sign-ins need you present. Treat the current browser session as one-shot.

Smallest unblock: an App Password for intern@peanut.me. Sixteen characters, works over IMAP immediately, single-purpose, revocable — no GCP project, no service account, no domain-wide delegation. Domain-wide delegation with gmail.readonly is the durable fix and is unaffected by 2SV.

Will this get us penalised

No. But volume still has no upside.

Since the December 2022 link-spam update, Google neutralises low-quality directory links rather than penalising the site they point at. Manual actions for unnatural inbound links are rare and reserved for obvious paid-link networks, and any manual action would show up in Search Console, which we already have access to.

Two real caveats. Directories that require a reciprocal do-follow badge on peanutsplit.com are a link exchange — that lives on our own site, which is where manual actions actually bite. And because neutralised links never recover their value, mass submission buys nothing. The bot wall enforces that discipline anyway.
