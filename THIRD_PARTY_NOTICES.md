# Third-party notices — incomplete publication draft

This is a work register, not a complete notice bundle. Do not publish a source archive or container
using it as proof of compliance.

Known items include:

- Lucide icon paths under the ISC License and Feather-derived material under the MIT License; the
  current text is in `design/doodles/LUCIDE-LICENSE.txt` and must accompany every distribution that
  includes the derived output.
- Sniglet font files under SIL Open Font License 1.1; the complete OFL text and copyright notice must
  be added to each relevant source/binary distribution.
- JavaScript dependencies under their own package licenses; generate an exact lockfile-based notice
  report and SBOM for each release.
- Node/Alpine/container packages and generated browser assets, which are not covered by an npm-only report.

Knerd fonts, Peanut marks/mascots, portraits, generated design assets, content, translations, data,
and imported private-mono artifacts remain unresolved in the
[rights register](docs/current/RIGHTS-REGISTER.md). Absence from this draft is not clearance.
